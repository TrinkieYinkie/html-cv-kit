# Local fonts

Lora by Cyreal is bundled unchanged under the SIL Open Font License 1.1.
See [OFL.txt](OFL.txt). Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/lora).
Downloaded 6 October 2026; file renamed to Lora-Variable.ttf for easy paths.

The editorial theme uses this variable font for the name. Classic uses system Arial/Helvetica.
The builder embeds referenced font bytes and the full OFL notice in the exported HTML.
No Google Fonts request is made when opening an export.

To try a different OFL-licensed font, add its file and OFL.txt in a subfolder,
then point an @font-face rule in your theme to it. Keep license notices with font files.
The builder supports .ttf, .otf, .woff, and .woff2.
